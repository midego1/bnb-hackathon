The problem

  • Scooter shops in Thailand usually keep the tourist's passport (or a stack of cash) as the deposit.
  • At return the shop alone decides what each scratch costs. Renters fear bogus damage claims.
  • Shops face real damage with no proof: a few chat photos, if any.
  • Nobody neutral in between, and nobody goes to court over a few thousand baht.

Solution

The deposit sits in a contract made for this one rental. Neither side can move it alone.

  • The shop offers rent, deposit and period (7, 14 or 30 days) in baht. Agreement and pickup photos stay off-chain; only their SHA-256 fingerprints go on-chain.
  • The renter funds deposit + first rent in a stablecoin. Rent is paid out period by period.
  • At return an AI inspector drafts the split. One side proposes, the other accepts, one transaction pays everyone.

Timeouts protect the renter: owner silent 7 days, or the desk misses its 14-day deadline → full deposit back.

How it works

One rental, one contract, three ways out

Owner

createLease

Factory deploys an EIP-1167 clone with the terms and the agreement hash.

→
Renter

fund

Deposit + first rent period in the stablecoin, locked in the clone.

→
Anyone

releaseRent

Each due period. The first payout pays the one-time 10% fee.

→
AI inspector

Draft split

Pickup vs return photos + scooter memory. Report hash names agent #2921.

→
One party

propose

The split + report hash, on-chain.

✓ Agree

The other side calls accept: one transaction pays renter, owner and treasury.

⚖ Dispute

dispute → the dispute desk sees both parties' history and calls resolve within 14 days.

⏱ Silence

Owner silent 7 days or desk past 14 days: claimTimeout / claimArbiterTimeout, full deposit to the renter.

BNB Chain integration

Live on BSC testnet, a capped pilot on BSC mainnet

One escrow clone per rental

EscrowFactory deploys a 45-byte EIP-1167 proxy of RentalEscrow per rental. Funds isolated, no admin key over funds, not upgradeable. On-chain indexes by owner, renter and desk: no backend database.

Mainnet pilot (chain 56)

Factory 0x8d708713…0a2d3E, real USDT (BSC-USD). Caps on the factory: deposit ≤ 0.70, rent ≤ 0.30 per period, so one rental ≤ 1 USD; 5 USDT in all escrows. Caps never block a payout.

ERC-8004 agent #2921

The KeyScrow Inspector is registered in the ERC-8004 Identity Registry on BSC testnet (BNB Agent SDK). Its id is in every report hash; it speaks A2A, MCP and REST.

Greenfield · opBNB-ready

Evidence off-chain (Greenfield store when configured, R2 on Workers), SHA-256 on-chain. Plain Solidity: the deploy guard accepts opBNB testnet. Not deployed on opBNB yet.
